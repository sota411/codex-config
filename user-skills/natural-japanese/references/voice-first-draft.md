# 声のある下書き

旧 `stop-ai-slop-jp` の強みだった「主体・立場・具体性・リズム」を、現行の `natural-japanese` と両立する形で前段化したもの。実行時にアーカイブ済みskillを参照しない。工程はこのファイルだけで完結する。

## 位置づけ

ここで作るのは内部下書きである。完成稿は、書き手の声と内容の芯を作ってから、現行skillの文体憲法、文書型、lint、構造レビュー、読みやすさレビューへ渡して仕上げる。

適用するのは、次のどちらかに該当するときだけ。

- ゼロから本文を書く新規執筆
- 元の段落構成を保てないほど大きく書き直す改稿

誤字の修正、語句の置換、短い部分添削、score モードでは省略する。既存文書を大幅改稿する場合も、元の事実、意図、語調のうち有効なものを先に固定し、勝手に別人の文章へ変えない。

## 1. 下書きカードを作る

本文の前に、次の項目を頭の中か一時メモで一行ずつ決める。

- **文書種別**: 議事録、報告書、ガイド、技術記事、ブログ、エッセイなど
- **話者**: 誰の立場から書くか。組織名義なら、どの役割が判断を引き受けるか
- **読後の変化**: 読者に何を理解、判断、実行してほしいか
- **引き受ける主張**: 話者が根拠を持って言えることを一文で書く
- **接地材料**: 入力や調査で確認した固有名詞、数値、事例、体験
- **温度と濃淡**: どこを強く言い、どこを短く流し、どこを保留するか

接地材料が足りず、一般論で埋めるしかない場合は、まず§1-4の素材集めへ戻るか、ユーザーへ必要な事実を確認する。ユーザーが素材を持っていない、または提供しない場合は、内容が汎用的になる旨を明示したうえで進めてよい。

## 2. 声を先に作る

下書きでは次の順で内容を出す。

1. **話者を場に置く。** 「多くの人」「現代社会」「組織一般」へ逃げず、確認できる範囲で「私は」「このチームでは」「運用担当者が」のように、経験または判断の持ち主を定める。
2. **行為者を戻す。** 人が判断・選択・修正した出来事では、その人や役割を主語にする。ただし、システムが応答する、処理が失敗する、データが一定値を示すなど、技術的に正確な無生物主語まで機械的に人へ書き換えない。
3. **具体から書く。** 入力にある固有名詞、数値、出来事、比較条件を使う。もっともらしい経験、感情、発言、数値は作らない。
4. **主張を直接書く。** 「AではなくBだ」、否定の列挙、劇的な短文、煽る問いで起伏を作らず、伝えるべきBをまず書く。実際の誤解を訂正する対比は残してよい。
5. **小さな話を膨らませない。** 個人の感想や一度の出来事を、社会全体の教訓、思想、真理へ自動的に一般化しない。一般化するなら、範囲を示せる根拠を添える。
6. **重要度に沿ってムラを作る。** 文や段落の長さ、情報密度、結論の強さを内容に合わせて変える。人工的に文末を散らしたり、三項目を揃えたりしない。
7. **中間の評価を許す。** 根拠が「悪くない」「一部は有効」「まだ分からない」程度なら、その温度で書く。強い評価は強い根拠または明示された感情がある場合だけ使う。

## 3. 文書種別で声の出し方を変える

| 文書種別 | 前段で優先すること | 入れてはいけないもの |
|---|---|---|
| 議事録・報告書・ガイド・企画書 | 誰が何を決め、何を根拠に、次に何をするか | 作られた感情、毒、皮肉、くだけた語尾 |
| 技術記事・比較記事 | 試した条件、選んだ案、選ばなかった案、その理由 | 根拠のない断言、全製品への儀礼的な称賛 |
| ブログ・note・エッセイ | 入力に現れている一人称、体験の細部、自然な温度差 | 作られた体験、意図的な誤字、偽の言いよどみ |

見出しは、現行skillの§1-2と該当する doctype を優先する。旧skillの「命題型見出しを一律に避ける」という規則は持ち込まない。ブログやエッセイで大げさな主張見出しになる場合だけ、題材や行為を表す素直な見出しへ戻す。

毒、皮肉、自虐、口語的な崩しは、人間らしさを演出する部品ではない。元資料、文体プロファイル、またはユーザーの明示した語調に実在するときだけ、目的に必要な範囲で残す。誤字、脱字、句読点の欠落は意図的に加えない。

## 4. 現行工程へ渡す

内部下書きができたら、次を固定したまま§2以降へ進む。

- 確認済みの事実、数値、引用、固有名詞
- 話者と読者
- 主メッセージと判断の方向
- 元資料に根拠がある感情や文体上の特徴

後段では、文体憲法と文書型に合わせて構成と表現を整え、lint とレビューで問題を収束させる。その際、整えること自体を目的にして、話者の立場、具体例、内容に沿った濃淡まで均さない。

伝聞表現や不確実表現は、情報源が伝聞である場合、または事実が未確認である場合にだけ使う。「人間らしく見せる」ために「らしい」「そうだ」「気がする」を足さない。不確実性の表示方法は文体憲法に従う。
