# 160K-AnnivPack 書体一覧

素材ルート：`$HOME/.local/share/design-assets/160K-AnnivPack-FREE/`

2026-09-06に提供ZIP、同梱の全体見本、`fc-scan`で確認。通常28書体・30ファイル、コラボ2書体・2ファイル。全ファイルが英字A–Z/a–zを収録し、漢字は未収録。日本語用フォントとしては扱わない。記号・数字を含む実際の使用文字は採用時に確認する。

特徴・用途は全体見本に基づく選定の目安。候補を絞ったら表の見本を開く。全体比較には素材ルートの`sample.png`を使う。表のOTF・見本・`readme.txt`は各「フォルダー」の直下にある。
