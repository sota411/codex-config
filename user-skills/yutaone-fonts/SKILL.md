# ゆうたONEフォント集

## 選び方

- 制作物の雰囲気、既存の書体指定、可読性、対象文字に合う場合に使う。ユーザーによる採用の事前確認は不要。明示された書体やブランド規定を優先する。
- [書体一覧](references/catalog.md)で候補を絞り、対象書体の同梱見本を開いて形を確かめる。特徴欄は選定の手掛かりであり、名前だけで判断しない。
- 30書体・32ファイルは欧文向け。日本語本文用には扱わず、実際に使う文字の収録範囲と描画結果を確認する。欠けた文字を別書体で黙って補わない。
- 適した候補がなければ使わない。採用した場合は、完了報告に書体名と使用箇所・理由を短く添える。

## 素材の場所

素材のルートは `$HOME/.local/share/design-assets/160K-AnnivPack-FREE/`。
`sample.png` が全体見本。各書体フォルダーにOTF、見本画像、`readme.txt`がある。
書体名からファイル名を推測せず、一覧の実ファイル名を使う。

素材はスキルのGitリポジトリに含めない。別端末では正規に取得したZIPを同じ場所へ展開する。この端末の元ZIPが残っている場合は次の標準コマンドで復元できる。

```sh
unzip -n "$HOME/Downloads/160K-AnnivPack-FREE.zip" -d "$HOME/.local/share/design-assets"
```

素材が欠損している場合は、欠けたパスと復元方法を示す。ZIPもなければユーザーに正規取得した素材の場所を確認し、別の素材へ黙って置き換えない。

## 利用条件

公開利用を伴う採用時は、[配布元の現行規約](https://docs.google.com/document/d/1jzKjcBY7Kni8GaGqFhJaeS2VThokrYWUysKsHnFCxhQ/edit)と対象書体の`readme.txt`を確認する。以下は2026-09-06取得時の要点。変更があれば現行の条件に従う。

- 制作する本人によるゆうたONEのフォローが必要。所有する対象SNSごとの条件は規約のFAQで確認する。未フォローの場合は、非商用でも個人・家庭内等のクローズドな利用に限られる。現在のユーザーのフォロー状況は未確認。
- NamelessFlameはUnnämed、GaenSansserifは火消魂のフォロー条件もある。各readmeを確認し、各コラボ相手の公式制作物と誤認させない。
- 公開利用の条件が不明な場合だけ、必要な事実をユーザーに確認する。同じ利用者・条件で確認済みの内容や採用の承認は聞き直さない。返答がなければ公開利用へ進めない。スキルの導入はフォロー済みの証拠にならない。
- フォントデータ自体の再配布・販売は禁止されており、システムへ組み込む場合は第三者が取り出せない形が求められている。通常の`@font-face`による配信を、この規約だけで許可されたものと判断しない。別途その用途の許諾が確認できた場合に扱う。WOFF化・サブセット化・難読化だけで条件を満たしたとは扱わない。
- Web向けには、採用した見出し等をローカルで画像化する方法を基本とする。フォントデータや再利用可能な全文字セットを公開成果物に含めない。固定文字列の素材化にもFAQの条件があるため確認する。
- 書体の原型を保ったロゴ等の商標登録、他者の書体利用を制限する行為を避ける。クレジット表記は任意。

## 採用後の制作

- 既存の制作ツールへ対象OTFを直接指定する。例えばImageMagickの`-font`には一覧のOTFの絶対パスを渡せる。全書体のOSインストールは不要。
- 同梱の見本画像は書体の比較に使い、そのまま完成素材として転載しない。
- 実際の文字列を描画し、欠字、文字の切れ、装飾部分、背景とのコントラストを確認する。代表的な収録範囲は`fc-scan --format '%{charset}\n' FONT.otf`で確認できる。
- Webへ画像を組み込む場合は、用途に応じた代替テキストと見出し構造を保持する。情報が画像だけに閉じないようにする。
